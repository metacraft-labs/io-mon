# Getting Started

This section introduces `io-mon`, its architecture, installation methods, and basic workflows.

- [Overview](/getting_started/overview) — why `io-mon` exists, how interposition works across platforms, and how the completeness guarantee safeguards incremental build correctness.
- [Installation](/getting_started/installation) — install pre-built packages via `apt`, `rpm`, `brew`, `scoop`, `nix`, the one-line install script, or build from source.
- [Quickstart](/getting_started/quickstart) — capture dependencies from a build command using `io-mon run`, inspect the resulting depfile with `io-mon inspect`, and parse it in Nim.
